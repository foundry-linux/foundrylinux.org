Two mechanisms, deliberately

Rows 1–2 are written by wf-game-create directly into ~/.local/share/applications/. Nothing in the container ships a “Donkey Kong” desktop entry, so there is nothing to export.

Row 3 comes from distrobox-export --app run inside wf-tools-heavy. Ghidra and the vintage emulators do ship desktop entries; the (Foundry heavy tools) suffix is --export-label.

distrobox create --no-entry keeps Distrobox from adding a fifth, generic entry per game.

wf-game-donkey-kong.desktop

Exec
wf-game donkey-kong
Icon

X-Foundry-Game
donkey-kong

X-Foundry-Game is the teardown handle — wf-game rm greps for it rather than guessing filenames, so both entries and the icon go together.
